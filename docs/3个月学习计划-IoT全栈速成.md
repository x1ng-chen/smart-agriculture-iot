| **Modbus 协议** | ❌ 永不过时 | 1979 年诞生，工业界用到现在，比你我年龄都大 |
| **ESP32 教程** | ⚠️ 框架版本会变 | ESP-IDF 版本号在涨（当前 v5.3），但外设驱动 API 保持兼容。优先选 **2025-2026 年发布** 的视频 |
| **Vue3 教程** | ⚠️ 优先看新版 | Vue3 核心 API 已稳定，但 2026 年的课会带 AI 编程 + Vite 最新配置。老课也能看，但优先搜 "2026" |
| **Node.js 教程** | ⚠️ 框架版本会变 | Express 几乎不变，但优先选 2025+ 的课（新语法、ESM 模块、更好的错误处理实践） |
| **Docker 教程** | ⚠️ 选新版 | Docker 核心概念 10 年没变，但 2026 版会覆盖国内镜像源配置、新 CLI 语法、国产系统适配 |

> **核心原则**：基础知识（语言/协议/操作系统）——不过时，看经典教程就好；框架/工具/云平台——选近 1-2 年的教程，避免版本踩坑。

## 📝 简历项目描述参考

### 简历上的项目名称

> **智慧农业 AIoT 灌溉系统**（全栈开发 + 嵌入式）

### 项目描述（面试 1 分钟版本）

> 我独立完成了一套从硬件到 AI 的全链路智慧农业灌溉系统：
> - **硬件层**：基于 RISC-V 架构的 BearPi-HM Nano + E53 传感器模组，C 语言固件运行在 LiteOS RTOS 上，通过 MQTT 协议直连华为云 IoT 平台
> - **云平台层**：华为云 IoTDA 设备管理 + IAM Token 认证 + Webhook 数据路由，支持设备影子、命令下发、规则引擎
> - **后端层**：Node.js + Express + MySQL，实现 RESTful API、JWT 认证、微信一键登录
> - **前端层**：Vue3 + Vite + Pinia + ECharts 实时仪表盘 + 微信原生小程序双端
> - **AI 层**：MiMo v2.5 大模型通过 Function Calling 实现智能灌溉决策 + 异常检测
> - **部署运维**：FRP 内网穿透 + Docker 容器化 + 阿里云 ECS

### 面试必背关键词

- MQTT QoS 0/1/2、遗嘱消息、发布/订阅
- FreeRTOS 任务调度、互斥量、优先级反转
- IoT 设备影子、规则引擎、命令下发
- JWT 认证流程、RESTful API 设计
- Docker 镜像分层、docker-compose 编排
- Node.js 事件循环、非阻塞 I/O
